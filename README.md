# Yassine El Ghazi — Cybersecurity portfolio

A fast, static portfolio for a cybersecurity engineering student at UEMF interested in reverse engineering and malware analysis: selected projects, CTF team achievements, technical skills, education, and public contact details.

**Live site:** https://yassine-el-ghazi.github.io/

![Desktop preview of Yassine El Ghazi's reverse-engineering themed portfolio](docs/preview.webp)

## Stack
Astro 7, strict TypeScript, semantic HTML, custom responsive CSS, and GitHub Pages. Geist and Geist Mono variable fonts are self-hosted (sans for reading, mono only for addresses, labels, and technical metadata). No analytics, backend, runtime API calls, or third-party embeds; the only JavaScript is one small inline script for navigation state.

## Local development
Requires Node.js 22.12+; CI uses Node.js 24.

```sh
npm ci
npm run dev
```

## Production checks
```sh
npm run check
npm run build
npm run audit:site
npm run preview
```

`check` validates Astro and TypeScript. `audit:site` checks generated internal links and fragment targets, duplicate IDs, required metadata/assets, unexpected external or bundled client scripts, text-size floor, private-wording guard, and common private-data patterns in source. These checks complement manual privacy review; they do not prove that all possible secrets are absent.

## Content structure
```text
src/
  components/       # Header, hero, work, research, CTF log, stack, about, contact
  components/writeup/ # Disasm, HexDump, Registers, MetaTable, Figure for future analyses
  content/writeups/ # Markdown writeups (see docs/WRITEUPS.md); _template.md is ignored
  data/             # Profile, skills, projects, competition highlights
  layouts/          # Shared document and SEO metadata, writeup layout
  pages/            # Homepage, custom 404, /writeups index and [slug]
  styles/           # global.css (home) and writeup.css (research pages)
  data/hero-sample.json  # generated by scripts/hero-sample/generate.py (needs gcc + binutils)
scripts/            # Build audit
.github/workflows/  # Checks and Pages deployment
```


## Deployment
The repository name matches the GitHub account: `Yassine-El-Ghazi.github.io`. Astro's `site` is the root URL with no project `base` path. In **Settings → Pages**, select **GitHub Actions** as the source.

Every push to `main` installs locked dependencies, checks types, builds, audits the site, uploads only `dist/`, and deploys to GitHub Pages. Pull requests run checks without deployment. Actions are pinned to immutable commit SHAs; deployment has scoped Pages and OIDC permissions. No private token is embedded in the site or workflow.

## Design and accessibility
- Near-black neutral palette with cold blue, muted teal, and sparing amber accents; a hero workbench generated from a real gcc/objdump build of a small C routine (`scripts/hero-sample`); a pipeline diagram of the malware detector's documented workflow.
- Semantic headings and landmarks, skip link, visible keyboard focus, descriptive links.
- Mobile layouts, fluid type, reduced-motion support, and no runtime dependencies.
- Canonical URL, Open Graph and Twitter text metadata, favicon, sitemap, robots.txt, and custom 404.
